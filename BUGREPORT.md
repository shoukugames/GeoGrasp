# Reporting a Bug in GeoGrasp

Thank you for helping make GeoGrasp better! 🌍🧩

## Where to send it

- **Email:** [info@shoukugames.org](mailto:info@shoukugames.org) — subject line: `GeoGrasp bug: <short summary>`
- **Website:** <https://shoukugames.org/>

## Before you report

1. Check that you are running the latest version (the version number is shown on the title
   screen tile **Credits** and in the Credits panel — currently **v0.1.0**).
2. Try restarting the game.
3. If the problem is about the camera / hand tracking, try switching **Control → Mouse** and back
   to **Hands** on the title screen, and make sure no other app (video call, etc.) is using the camera.

## Please include

Copy this template into your email and fill it in:

```text
GeoGrasp version: v0.1.0
Operating system:  (e.g. Windows 11, Ubuntu 24.04, Debian 12)
Installed with:    (.deb / Setup .exe / portable .exe / from source)
Language:          (English / 日本語)
Mode:              (Easy / Medium / Hard / Capital Cities / Tutorial / For Parents)
Map region:        (World / Africa / Asia / Europe / North America / South America / Oceania)
Control:           (Hands (camera) / Mouse)
Camera model:      (if the problem is hand tracking)

What happened:
What I expected to happen:
Steps to reproduce:
  1.
  2.
  3.
How often:         (always / sometimes / once)
```

Screenshots or a short screen recording of the **game window** are very helpful.

> **Privacy note:** please do **not** send photos or videos of children. GeoGrasp never records
> the camera, so there is nothing for you to attach from the camera itself.

## Developer logs (optional)

If you started GeoGrasp from a terminal (`geograsp` on Linux, or `npm start` from source), any
error messages printed there are useful. Inside the game you can also press
`Ctrl+Shift+I` to open the developer console and copy any red error messages.

## Wrong country data?

Country names, capitals and borders can be politically sensitive and change over time. If you
think something is wrong (in English or Japanese), please tell us which country, what the game
shows, and what you believe is correct — a source link helps a lot.
